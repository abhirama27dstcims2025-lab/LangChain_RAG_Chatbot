## 4. Machine Learning Projects

### Project 1: Medical Insurance Cost Prediction

This project focuses on predicting medical insurance charges using customer and health-related features, including age, sex, BMI, number of children, smoking status, and geographical region.

The project involves exploratory data analysis, handling categorical variables, preprocessing numerical features, and training machine learning models.

The target variable, insurance charges, is right-skewed, so log transformation was explored to reduce skewness and improve modeling behavior.

I experimented with Random Forest optimization using Optuna and XGBoost optimization using a Genetic Algorithm.

Reported model results include:
- Random Forest: R² = 0.8773, RMSE = 4364.36, MAE = 2473.35.
- XGBoost: R² ≈ 0.8781, RMSE ≈ 4350.28, MAE ≈ 2509.43.

These results help compare the predictive performance of different models.

### Project 2: Bank Customer Churn Prediction

This project aims to identify customers who are likely to leave a bank. The dataset includes features such as credit score, age, tenure, account balance, number of products, credit card ownership, activity status, estimated salary, geography, and gender.

The project includes data preprocessing, categorical encoding, feature scaling, class imbalance handling using SMOTE, and logistic regression modeling.

I evaluated the model using a confusion matrix, precision, recall, and accuracy. I am interested in improving churn prediction with XGBoost, Optuna-based hyperparameter tuning, and SHAP for model interpretation.

### Project 3: Survival Analysis Using ACTG320 Data

This project explores survival analysis using the ACTG320 dataset, which contains information about treatment, survival time, censoring, CD4 count, age, and other patient characteristics.

The planned analysis includes:
- Kaplan–Meier survival estimation.
- Log-rank tests for comparing survival curves.
- Cox proportional hazards regression.
- Hazard ratios and confidence intervals.
- Testing the proportional hazards assumption.
- Concordance index evaluation.
- Exploring Random Survival Forest and XGBoost survival models.

The purpose is to understand time-to-event outcomes and evaluate how patient characteristics and treatment relate to survival.

## 5. Research Project: Hybrid Neural Architecture Search

My research interest includes developing a Hybrid Neural Architecture Search (NAS) framework.

The project explores the use of Genetic Algorithms to discover effective neural network architectures. Genetic Algorithm operations include selection, crossover, and mutation.

The framework considers concepts such as weight inheritance, Lamarckian learning, and SynFlow-based evaluation. The research explores image classification using CIFAR-10 and text classification using datasets such as AG News and IMDB.

The evaluation criteria include predictive accuracy, F1-score, inference latency, and parameter efficiency.

I am particularly interested in combining evolutionary optimization with neural network training to find architectures that balance predictive performance and computational cost.

## 7. Interests in Artificial Intelligence and RAG

I am interested in learning how large language models can be combined with external knowledge sources to build useful AI applications.

One of my learning goals is to develop a Retrieval-Augmented Generation (RAG) application using LangChain.

A RAG application typically involves:
1. Collecting documents that contain relevant information.
2. Splitting documents into smaller chunks.
3. Converting chunks into numerical representations called embeddings.
4. Storing the embeddings in a vector database such as FAISS or Chroma.
5. Retrieving relevant chunks when a user asks a question.
6. Providing the retrieved context to an LLM to generate an answer grounded in the available documents.

I want to build practical applications that can answer questions about personal documents, technical projects, academic notes, and other knowledge sources.
